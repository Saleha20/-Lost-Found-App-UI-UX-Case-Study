# -Lost-Found-App-UI-UX-Case-Study
A mobile application designed to simplify the process of reporting, searching, and recovering lost items. This project focuses on creating an intuitive, user-centered experience that enables users to reconnect with their belongings through a secure and organized platform.

---

## Project Overview

The Lost & Found App addresses the common challenge of recovering misplaced belongings by providing a centralized platform for reporting lost and found items. The design emphasizes usability, accessibility, and trust through a streamlined reporting process and secure claim verification.

---

## Problem Statement

People often lose valuable belongings in universities, workplaces, and public spaces. Traditional lost-and-found methods are slow, unorganized, and unreliable, making it difficult for users to recover their items.

---

## Goal

Design a mobile application that enables users to:

- Report lost and found items
- Search for matching items
- Track item status
- Securely claim recovered items
- Improve communication between users and administrators

---

## Features

- User authentication
- Report lost items
- Report found items
- Search and filter functionality
- Claim requests
- Admin management interface
